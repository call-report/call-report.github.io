## Repository Overview

This is the GitHub Pages deployment repository for Call.Report documentation site (https://call.report/). The site provides resources for importing, analyzing, and reviewing Federal financial system regulatory ("Call Report") data.

## Repository Structure

- **production branch**: Contains the deployed static HTML files generated by MkDocs
- **main branch**: Contains only the LICENSE file
- **docs/**: Source markdown files for documentation (when rebuilding)
- **mkdocs.yml**: MkDocs configuration file

## Key Directories

- `docs/` - Source markdown documentation files
- `code/` - Code Library documentation pages (built output)
- `datalibrary/` - Data Library documentation pages (built output)
- `datasources/` - Data Sources documentation (built output)
- `releasenotes/` - Release notes documentation (built output)
- `license/` - License information pages (built output)
- `assets/` - Static assets (CSS, JavaScript, images)
- `search/` - Search index files

## Build and Deployment

### Building the Documentation

1. **Install MkDocs and dependencies**:
```bash
pip install mkdocs mkdocs-material pymdown-extensions
```

2. **Build the static site**:
```bash
mkdocs build
```

3. **Deploy to GitHub Pages** (production branch):
```bash
mkdocs gh-deploy --branch production
```

### Local Development

1. **Serve documentation locally**:
```bash
mkdocs serve
# Site will be available at http://127.0.0.1:8000
```

2. **Live reload during development**:
The local server automatically reloads when you save changes to markdown files.
